PROMPT RÉSUMÉ — Connected ChronoTrack
Tu es en train de développer une application web appelée Connected ChronoTrack (index.html sur mkharsa.github.io/ChronoTrack/), connectée à Firebase Firestore (projet chronotrack-8c563).

Stack technique

HTML/CSS/JS vanilla — un seul fichier index.html
Firebase Firestore pour la persistance temps réel
Hébergé sur GitHub Pages
Pas de framework, pas de build


Ce que fait l'application
3 onglets dans une barre de navigation en bas :
📋 Sessions

Liste de toutes les sessions (nom, date, distance par défaut, participants)
Créer une session : nom (ex: 10x400m), distance extraite automatiquement du nom, date, participants sélectionnés parmi une liste globale ou créés à la volée
Ouvrir une session → vue Chrono
Supprimer une session individuellement (bouton 🗑)
Suppression groupée : checkboxes toujours visibles à gauche de chaque carte → barre "Supprimer" apparaît quand au moins une est cochée → confirm() natif pour confirmer

⏱ Chrono (vue intérieure d'une session)

Liste des participants avec checkbox de sélection
Boutons START / STOP / RESET en bas
START → démarre le chrono pour les participants sélectionnés, remet les laps à zéro
STOP → enregistre la rep, remet le chrono à 0 pour la prochaine rep
Chaque participant accumule ses reps (Rep 1, Rep 2...) avec leur temps
Pendant la course : bouton 🚩 Lap individuel par participant
Les laps sont stockés par rep (p.repLaps = [[laps rep1], [laps rep2], ...])
Affichage en colonnes : chaque rep a sa colonne avec ses laps dessous (durée du lap + temps total @ XX:XX)
Moyenne des reps affichée en vert
La distance est pré-remplie au STOP (depuis lastDist > defaultDist > nom session) — si inconnue, modal minimaliste
RESET : remet tout à zéro ET supprime les séries Firebase du jour

📅 Calendrier

S'ouvre sur le mois et le jour courants
Jours avec séries en vert avec point
Clic sur un jour → détail des séries affiché en dessous avec scroll automatique
Ajout manuel de séries (distance + temps par participant)
Bouton ✓/✗ sur chaque entrée pour inclure/exclure de la moyenne de progression

📈 Progression

Moyenne globale (toutes distances) par personne en haut
Filtres par distance
Vue par séance ou par mois
Tableau par personne : période, moyenne, nombre d'essais, évolution (vert = meilleur, rouge = moins bon)
Mise à jour instantanée après chaque STOP ou modification calendrier


Modèle de données Firebase
/sessions/{id}           → name, date, defaultDist
/sessions/{id}/participants/{id} → name, lastDist
/participants/{id}       → name (liste globale réutilisable)
/series/{dateKey}_{id}   → dateKey, dist, entries:[{pid, name, timeMs, include}]
Règles importantes :

laps, times, repLaps sont locaux uniquement (non persistés dans Firebase)
Seul lastDist est persisté par participant
Les séries sont le seul canal de persistance des temps chronométrés
